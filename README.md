# Cows & Bulls

> *Hey Wordle! who's your daddy?*

A retro-cyberpunk 5-letter word guessing game engineered for crisp 4K clarity across Android & Apple iOS vertical 9:16 portrait phones (up to 4× Super-Retina DPR) as well as 2K, 2.5K, 3K, 3.5K ultrawide, and 4K UHD desktop monitors. Features 10 attempts, UK English dictionary validation, 3 Oracle Hints, CRT synthwave visuals, and a procedural 128 BPM melodic retro-trance soundtrack.

## Deploy to GitHub Pages

1. Create a new public repository on GitHub (e.g. `cows-and-bulls`).
2. Upload `index.html`, `README.md`, and the `assets/` folder (or push with Git).
3. Go to **Settings → Pages**, set **Source** to **Deploy from a branch**, choose `main` and `/ (root)`, and click **Save**.
4. Your live game will be available at `https://<your-username>.github.io/<repo-name>/` within ~1 minute.
