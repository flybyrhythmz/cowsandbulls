# Cows & Bulls

> *Hey Wordle! who's your daddy?*

A retro-cyberpunk 5-letter word guessing game engineered for crisp 4K clarity across Android & Apple iOS vertical 9:16 portrait phones. Features 10 attempts, English dictionary validation, 3 Oracle Hints, deduction note markers, CRT synth wave visuals, and a melodic retro-trance soundtrack.

## Deploy to GitHub Pages

1. Create a new public repository on GitHub (e.g. `cows-and-bulls`).
2. Upload `index.html`, `README.md`, and the `assets/` folder (or push with Git).
3. Go to **Settings → Pages**, set **Source** to **Deploy from a branch**, choose `main` and `/ (root)`, and click **Save**.
4. Your live game will be available at `https://<your-username>.github.io/<repo-name>/` within ~1 minute.
