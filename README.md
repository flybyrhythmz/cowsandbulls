# Cows & Bulls

> *Hey Wordle! who's your daddy?*

A retro-cyberpunk 5-letter word guessing game (strictly 5 unique letters in both secret words and guesses) engineered for crisp 4K clarity across Android & Apple iOS vertical 9:16 portrait phones (up to 4× Super-Retina DPR) as well as 2K–4K desktop monitors. Features 10 attempts, UK English dictionary validation, **Easy / Hard** hint modes (exact-position hints vs. random-position letter hints), CRT synthwave visuals, procedural 128 BPM melodic retro-trance music, Firebase Google/Facebook cloud stat sync (`cows-and-bulls-stats`), and native 9:16 PNG Story Card sharing with mode and hint counts for Instagram and mobile apps.
